# Inoffizieller Fork der „alten“ pr0gramm-App für Android

Die aktuelle Version der **offiziellen** pr0gramm-App gibt es unter https://pr0.app oder https://pr0.app/app.

Fork von: https://github.com/pr0gramm-com/pr0gramm-app

## Hintergrund
Alte Männer wie ich hassen Veränderungen. Wir leben „Früher war alles besser!“ und „Alles bleibt so, wie es ist!“.
Daher ist das hier ein inoffizieller Fork der guten alten Pr0-App, aber auf die neue API umgebaut. Damit können wir die App vielleicht noch ein bisschen länger nutzen, auch wenn der Chef die alte API dichtmacht und die offizielle Unterstützung endgültig endet.
Ob das wirklich klappt, wird sich zeigen.

## Einschränkungen
Ich bemühe mich, API-Änderungen nachzuziehen und die App lauffähig zu halten. Ich fixe vielleicht sogar ein paar Bugs, wenn sie mir hier als Issues eingereicht werden.
Was ich nicht tun werde: neue Features implementieren oder Features aus den neuen und offiziellen Apps portieren. Wenn ihr die haben wollt, müsst ihr wechseln.

## Unterstützung
Wenn ihr die App hier verwendet, kauft euch Pr0mium oder spendet etwas.
Ich meine es ernst.
Keine Ahnung, ob die Werbeeinblendungen hier noch sauber funktionieren und das Pr0 daran verdient. Daher seid fair und lasst ein paar Groschen da!
